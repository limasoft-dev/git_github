O que é um Fork

Um fork no GitHub é, uma cópia pessoal de um repositório de outra pessoa na sua própria conta do GitHub.

O que é um Pull Request

Um Pull Request é uma solicitação para que alterações que você fez em um repositório sejam aceitas e mescladas no repositório original (geralmente de outra pessoa ou de uma equipe).

O que é um Clone

Um clone no Git é o ato de baixar uma cópia completa de um repositório remoto (que está na nuvem) para o seu computador local.
