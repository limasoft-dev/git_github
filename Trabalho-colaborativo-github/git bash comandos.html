O que faz o comando git clone url

Baixa uma cópia completa de um repositório remoto (junto com todo o histórico) para o seu computador pela primeira vez.

O que faz o comando git remote - v

Mostra quais são os links dos repositórios remotos conectados ao seu projeto local

O que faz o comando git fetch

Baixa todas as novidades e atualizações do repositório remoto para o seu computador, mas não mexe no código dos arquivos em que você está trabalhando ainda. É uma forma segura de verificar o que mudou.

O que faz o comando git pull

Ele baixa as alterações do repositório remoto e já as aplica automaticamente nos arquivos da sua branch atual.

O que faz o comando git push

Envia os seus commits locais (já salvos no seu computador) para o repositório remoto no GitHub, atualizando a nuvem com o seu trabalho.

O que faz o comando git branch

Lista todas as branches locais do projeto e mostra em qual você está trabalhando no momento.

O que faz o comando git checkout -b "nome-da-branch"

Cria uma nova branch e muda para ela imediatamente. Cada pessoa na equipe costuma criar uma branch com seu próprio nome ou com o nome da funcionalidade que vai desenvolver.

O que faz o comando git checkout "nome-da-branch"

Alterna entre diferentes branches no seu computador.

O que faz o comando git merge "nome-da-branch"

Junta o código de uma branch na outra (por exemplo, juntar a branch de uma funcionalidade na branch principal main).
