Os Comandos do git classificados

Aprenderas alguns comandos do Git

Comandos básicos

Comando Descrição
git init Cria um novo repositório Git.
git clone "url" Clona um repositório remoto.
git status Mostra arquivos modificados, rastreados e não rastreados.
git add . Adiciona todas as alterações à área de staging.
git commit -m "mensagem" Registra as alterações no repositório.

Visualização e histórico

Comando Descrição
git log Exibe o histórico de commits.
git log --stat Mostra resumo das alterações.
git diff Mostra diferenças entre versões.
git show "hash" Mostra detalhes de um commit específico.

Trabalhando com branches

Comando Descrição
git branch Lista branches.
git checkout -b nome Cria e muda para um novo branch.
git merge nome Mescla um branch ao atual.

Repositórios remotos

Comando Descrição
git remote add origin "url" Adiciona repositório remoto.
git push origin master Envia commits para o repositório remoto.
git pull Baixa e mescla alterações do remoto.

Desfazendo alterações

Comando Descrição
git checkout nome_do_arquivo Desfaz mudanças antes do commit.
git reset HEAD nome_do_arquivo Remove arquivo da área de staging.
git reset --soft/mixed/hard "hash" Desfaz commits em diferentes níveis.
git revert "hash" Cria commit que desfaz outro commit.

Configurações úteis

Comando Descrição
git config --global user.name "O teu Nome" Define nome do usuário.
git config --global user.email "email@exemplo.com" Define e-mail.
git config --list Lista configurações.
