A História do Git e do GitHub

Como Tudo Começou

O Git foi criado no ano de 2005 por Linus Torvalds, o Homem que inventou o Linux. Ele precisava de uma ferramenta rápida e segura para gerir o código do seu sistema operativo, porque as opções da altura eram muito fraquinhas.

Cronologia das Ferramentas

Para perceberes melhor como as coisas evoluíram ao longo dos anos:

Ano O que aconteceu?
2005 Linus Torvalds cria e lança a primeira versão do Git.
2008 É lançado o GitHub, levando o Git do terminal para a internet.
2018 A Microsoft compra o GitHub para apoiar os programadores do mundo inteiro.

As Grandes Vantagens do Git

O Git revolucionou o trabalho em equipa na Programação através de três pontos chave:

  • Branches: Cada aluno trabalha na sua ramificação sem estragar o projeto principal.
  • Histórico: Podemos voltar atrás no tempo se o código se partir.
  • Partilha: É super fácil juntar o código do grupo inteiro no fim.
